Wazuh MSSP
Hub-to-Spoke.

Hub centralizado na Contabo. Spokes onde o cliente já está — Contabo, Azure, AWS ou on-premises.

Arquitetura em 3 camadas

Camada 3 · Hub
Wazuh Hub SOC
Indexer OpenSearch · Dashboard MFA · índices separados por cliente · Shuffle SOAR
alertas 9200/HTTPS
Camada 2 · Spoke
Wazuh Manager + Filebeat
1 por contrato · descarta ~95% · fila 15 GB · contingência 7 dias
eventos 1514/TLS
Camada 1 · Endpoints
Agente Wazuh 4.14.6 + Sysmon
Windows com Sysmon v15 · SHA256 + IMPHASH · FIM · SCA · inventário

Spoke roda onde o cliente já está

☁ Contabo VLAN
VPS na rede privada · sem tráfego pela internet · latência mínima ao Hub
⬡ Azure
VM no tenant do cliente · integra M365 e Azure AD nativamente
◆ AWS
EC2 na conta do cliente · 9200/HTTPS internet TLS
⬛ On-premises
VM no datacenter físico · dados não saem do site

Regra invariante Todos os Spokes enviam apenas alertas ao Hub — nunca logs brutos. O Spoke processa localmente e descarta ~95–99% dos eventos.

Compliance nativo SCA com policies YAML customizadas por cliente — CIS Controls, LGPD e baselines próprios da ness.
